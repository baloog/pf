Built an AI-powered screen habit coach app using Flutter, Supabase, Android native integration, app usage tracking, reminders, and voice feedback.

Flutter • Supabase • Dart • Android MethodChannels • ElevenLabs

Highlights

  • Built authentication and app structure using Flutter and Supabase.
  • Integrated Android native foreground app tracking through MethodChannels.
  • Added session tracking, daily usage aggregation, and app usage limits.
  • Created reminder logic with near-limit and exceeded-limit alerts.
  • Integrated ElevenLabs voice reminders.
  • Added dark mode and session analytics.

This project supports healthier mobile habits by tracking usage and providing coaching feedback.
