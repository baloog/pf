Project overview

AI Research / Time-Series Benchmarking

Built a benchmark framework comparing LSTM and LLM-inspired methods for synthetic and real-world time-series classification and forecasting.

Python • LSTM • Transformers • SHAP • Attention Visualization • NumPy • Pandas

Highlights

  • Compared LSTM, Prompt Design, Direct Query, and Tokenization pipelines.
  • Evaluated both time-series classification and forecasting tasks.
  • Achieved 100% classification accuracy with LSTM and Tokenization approaches.
  • Achieved best forecasting performance with LSTM at MAE 0.0239.
  • Added SHAP explainability and attention visualization.
  • Tested synthetic and real-world evaluation settings with prompt engineering experiments.

Problem Statement

This project benchmarks modern time-series approaches using both LSTM and LLM-inspired methods.

Methodology

Use synthetic and real data to compare classification and forecasting pipelines, including prompt engineering and tokenization.
