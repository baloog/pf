Project overview

Healthcare ML / Classical Machine Learning

Created a 3-class clinical prediction system for heart disease severity using machine learning, class balancing, clustering analysis, and evaluation workflows.

Python • Scikit-learn • Pandas • NumPy • Random Forest • SMOTE

Highlights

  • Predicted no disease, mild disease, and moderate/severe disease classes.
  • Used SMOTE to reduce class imbalance impact.
  • Built a Random Forest-based classification pipeline.
  • Included confusion matrix and metric analysis.
  • Added clustering workflow explanations using KMeans, GMM, DBSCAN, and Agglomerative Clustering.
  • Designed the project for clinical-style model interpretation and reporting.

Problem Statement

This project aims to classify heart disease severity in a way that supports patient-level clinical decision making.
