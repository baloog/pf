Project overview

Medical AI / Longitudinal Analysis

Built a longitudinal chest X-ray analysis system for multi-label thoracic disease detection and patient-level disease progression tracking.

Python • PyTorch • ResNet-18 • OpenCV • NumPy • Grad-CAM

Highlights

  • Detected 8 thoracic diseases using a ResNet-18 based multi-label classifier.
  • Performed scan-level and patient-level prediction analysis.
  • Tracked disease trends as improved, worsened, or stable.
  • Integrated report mining and longitudinal progression analysis.
  • Achieved approximately 0.79 macro AUROC.
  • Generated Grad-CAM visualizations and bounding boxes for explainability.

Problem Statement

This project addresses the need for longitudinal monitoring of thoracic disease progression across repeated chest X-ray scans.

Methodology

Use multi-label classification, patient-level aggregation, report-based trend analysis, and explainability output.
