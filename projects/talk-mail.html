Project overview

Full Stack AI App / Voice Assistant

Created an AI-powered mail assistant web app with voice interaction, AI-generated replies, meeting extraction, and local mail/meeting workflows.

HTML • CSS • JavaScript • Node.js • OpenAI API • Speech Recognition • Text-to-Speech

Highlights

  • Built inbox and sent mail UI with compose modal.
  • Added browser text-to-speech for reading emails aloud.
  • Added browser speech recognition for voice replies and meeting inputs.
  • Created AI-generated email reply flow through backend route /generate-reply.
  • Created AI meeting extraction through backend route /schedule-meeting.
  • Stored local meetings and sent messages using localStorage.
