Project4Lonely

A multimodal machine learning project predicting UCLA loneliness levels using smartphone sensor and wearable data.

Project

Project overview

Mental Health ML / Multimodal Prediction

Built a multimodal machine learning project to predict UCLA loneliness levels using smartphone sensor data and Oura Ring wearable data.

Python • Pandas • Scikit-learn • XGBoost • SVM • Random Forest • Logistic Regression

Highlights

  • Combined Aware smartphone data and Oura Ring data.
  • Engineered features from sleep, screen usage, calls, battery usage, readiness, and activity metrics.
  • Trained Logistic Regression, SVM, Random Forest, and XGBoost models.
  • Achieved best performance with XGBoost at approximately 0.80 accuracy and 0.86 ROC-AUC.
  • Focused on participant-level aggregation and leakage-aware modeling.

Problem Statement

This project predicts loneliness using multiple data sources to inform healthier behavioral interventions.

Methodology

Use smartphone and wearable feature engineering with classical ML models to estimate loneliness levels.
